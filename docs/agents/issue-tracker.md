# Issue tracker: GitHub

Issues and specs live in KevinBacas/home-timeline on GitHub.
Use the gh CLI, resolving the repository from origin.

- Publish tickets with gh issue create.
- Read tickets with gh issue view <number> --comments.
- List tickets with gh issue list, including labels.
- Update labels with gh issue edit.
- Resolve tickets with gh issue close.
- For multiline content, write a temporary file and use --body-file.

PRs as a request surface: no.
